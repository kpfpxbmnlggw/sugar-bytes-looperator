## Overview

Looperator captures a rolling audio buffer and sequences slices, reverses, stutters, and filters across 16 steps, creating glitchy loop transformations that evolve with each bar cycle.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sugar Bytes Looperator** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Rolling Buffer** | Continuously captures incoming audio in a configurable loop length |
| **Slice Sequencer** | 16 steps each selecting a buffer position, reverse, and pitch |
| **Filter Lane** | Per-step filter cutoff sequencer for tone-sweeping loop mangling |
| **Stutter Control** | Gate length, repeat, and overdub controls for complex stutter patterns |
